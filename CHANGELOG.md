# Changelog

## 0.1.0 — 2026-11-06

First unofficial Windows preview: a click-through foreground-window sweater, an adapted upstream collection, Windows executable matching, tray controls, portable settings, exclusions, optional maximized-window borders and a reproducible .NET Framework build. The port follows the GPL-3.0 license and credits saragordic/window-sweaters and FelixKratz/JankyBorders.
