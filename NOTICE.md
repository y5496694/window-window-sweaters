# Attribution and modifications

This is an **unofficial Windows port** of [Window Sweaters](https://github.com/saragordic/window-sweaters) by **saragordic**. It is not an official release from the original author.

Window Sweaters is derived from [JankyBorders](https://github.com/FelixKratz/JankyBorders) by **Felix Kratz**. The upstream GNU General Public License, version 3, is preserved verbatim in `LICENSE`. All distributed source in this port is provided under GPL-3.0, preserving the upstream license.

Upstream snapshot: `4c9376bd774b09c9653c108c1961219edb16c33c`.

The collection in `src/Collection.cs` adapts the 47 built-in pattern charts from upstream `src/chart.c` and the 44 app-name rules from upstream `src/apps.c`. Palette values, stable colour selection and bowed V-stitch geometry in `src/Knit.cs` are adapted from upstream `src/knit.c`. `tools/import-collection.py` records how to regenerate the chart and rule data from that snapshot.

Windows changes by [y5496694](https://github.com/y5496694), November 2026:

- Replaced macOS CoreGraphics/private window APIs and Objective-C menus with a C# WinForms/GDI+ implementation using public Windows APIs.
- Added an alpha-layered, click-through, non-activating overlay that follows the foreground window.
- Added Windows executable aliases, a Korean/English tray menu, portable settings, per-process exclusions and a preview window.
- Added Windows build and packaging scripts, lifecycle/rendering checks and corresponding-source distribution.

The Windows renderer is a simplified adaptation; the original sculpted-yarn shader, specialised motif adjustments and all-window stacking behaviour are not reproduced exactly.

Application names belong to their respective owners and describe colourway inspiration. No affiliation or endorsement is implied. No upstream hero images, AI promotional mockups, screenshots or catalogue PDFs are bundled. `docs/preview.png` is generated by this port's renderer and is labelled as a rendered sample.
